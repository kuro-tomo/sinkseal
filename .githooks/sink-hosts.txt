# AgentGuard vendor API host table (catches SDK bypass via raw HTTP)
#
# A table that only matches on SDK names lets `requests.post("https://api.twilio.com/...")`
# sail through untouched. The sink is not the SDK — it's "the destination of an
# irreversible external action" — so the destination itself needs to be a scan target.
# If a host name appears in code that can execute, it needs an entry in the allowlist.
#
# [Why this is a separate file from sinks-default.txt]
# This file IS included in no-live-fire-check.sh's scan, but it is NOT used by
# sink-inventory-drift.sh's "ledger coverage" check. If the two were merged, adding a
# single host-name line for a vendor would make that vendor's SDK-call coverage look
# "complete" even if no SDK-call pattern for it exists at all. Host coverage and
# SDK-call coverage are not the same thing — keep them separate.
